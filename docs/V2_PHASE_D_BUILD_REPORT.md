## 1. 本阶段结论

阶段 D 已完成。通用采集契约已经通过红富士苹果、包装鸡蛋、明确部位猪肉和公共市场单位报价四类样本验证，可以严格区分商品身份、精确换算数量和保存点时价格。

规则采用白名单而不是标题猜测。缺少品种、产地、等级、保鲜状态、部位、包装或可靠数量时，来源版本进入待复核，不生成可信当前价。

## 2. 已交付内容

### 2.1 计量规范化

新增严格数量解析器，支持：

- 克、千克/公斤、斤到 `KG`；
- 毫升、升到 `L`；
- 枚、个、只以及 `2盒×15枚` 到 `PIECE`；
- 可审计的精确范围，例如 400～500g；
- 原单位、基本单位和包装内件数同时保留。

模糊数量、未知单位、计量维度冲突和非整数件数会显式失败，不使用浮点数或经验估计。

### 2.2 生鲜规则包

新增：

- `FreshAppleRule`：红富士、产地、等级、保鲜状态、包装、果径；
- `PackagedEggRule`：蛋品类型、产地、等级、保鲜状态、包装、蛋壳颜色；
- `FreshPorkRule`：猪肉部位、产地、等级、保鲜状态、包装、骨皮状态；
- 精确版本注册入口；
- 7 条生鲜品类树幂等种子和 `db seed-v2-fresh` 命令。

身份指纹改为优先使用基本数量，解决 `5kg` 和 `5000g` 形成错误新版本的问题。Repository 同步按规范基本数量判断身份相等，原始数量表达仍留在证据中。

### 2.3 脱敏重放

新增两个离线来源：

- 综合电商样本：5kg 红富士苹果、30 枚包装鸡蛋、500g 冷鲜去骨带皮猪五花肉；
- 公共市场样本：红富士一级果 6.80 元/500g 的人民币平均价。

样本连续重放两次，验证相同价格仍产生独立点时观察。苹果会员价作为拒绝事实保存，没有覆盖 79 元直接售价。
