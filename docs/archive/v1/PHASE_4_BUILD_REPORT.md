## 1. 本阶段边界

阶段 4 新增华为、OPPO、vivo 中国大陆官方直营商城 adapter，继续沿用 V1 数据口径：

- 只采集手机、平板、笔记本、台式电脑和手表；
- 只保存具体 SKU 的人民币无条件直接销售总价；
- 原价仅在页面明确给出时保存，否则为 `NULL`；
- 不采集国补、优惠券、会员、换购、月供、定金或到手价；
- 不采集荣耀、一加、iQOO、第三方配件或第三方商城；
- 不登录、不处理验证码、不调用受限内部接口、不绕过风控；
- 不绕过阶段 0 的生产授权门禁。

## 2. 公开页面只读复核

本阶段对公开入口做了低频只读检查，没有登录、下单或采集完整页面：

- 华为商城：<https://www.vmall.com/>；
- OPPO 商城：<https://www.opposhop.cn/>；
- vivo 官方商城：<https://shop.vivo.com.cn/>。

结论：

- 华为商品详情可能落到官方移动域名；程序只增加精确域名 `m.vmall.com`，且 adapter 仍限制 `/product/{数字}.html` 商品路径；
- 华为直接售价节点与国补、换购、积分等活动文案分开处理，条件价格出现在选中价格节点时整项拒绝；
- OPPO 只接受 `/cn/web/products/{数字}.html`，发现阶段排除一加、Care+、权益包、保障服务和外部平台链接；
- vivo 只接受本站 `/product/{数字}` 商品页，发现阶段排除 iQOO、NEX、第三方配件和外部链接；
- 三个站点的版本、颜色维度并非每类设备都同时存在，因此通用浏览器快照支持“可选规格维度”，单规格设备仍可形成一份可重放证据。

页面结构会变化，上述结论只作为 adapter 和 fixture 的开发依据，不等于生产访问授权。

## 3. 已完成实现

### 3.1 华为 adapter

- 华为手机、MatePad、MateBook、MateStation 和 WATCH 分类；
- 荣耀、WIKO、Hi nova、华为智选及范围外设备过滤；
- 官方产品 ID、SKU ID、版本、颜色、内存和容量保留；
- 划线原价、当前售价、现货、缺货、预约和预售状态解析；
- 国补、优惠券和换购文案与直接售价隔离；
- `www.vmall.com` 与官方移动商品页精确白名单。

### 3.2 OPPO adapter

- OPPO 手机、Pad 和 Watch 分类；
- 一加、Care+、权益包、保障服务和外部商城过滤；
- 版本、颜色、官方 SKU ID、直接售价和划线原价解析；
- 缺货、预约、预售和下架状态区分；
- 只允许 OPPO 商城精确商品路径。

### 3.3 vivo adapter

- vivo 手机、Pad 和 Watch 分类；
- iQOO、NEX、第三方配件和外部链接过滤；
- 版本、颜色、官方 SKU ID、直接售价和划线原价解析；
- 营销区优惠券和分期文案不污染直接售价；
- 下架与暂时缺货分别保存为 `OFF_SHELF` 和 `OUT_OF_STOCK`。

### 3.4 通用能力

- 内置 adapter 注册表扩展为五品牌；
- 浏览器 SKU 快照支持可选规格维度，兼容无版本或单规格设备；
- CLI 品牌帮助和镜像 adapter 列表同步为五品牌；
- 华为渠道种子增加 `m.vmall.com` 精确域名，不放宽到通配子域名；
- 既有质量校验、证据哈希、MySQL 命名锁、幂等入库和离线重放链路保持不变。

## 4. Fixture 与测试覆盖

提交的 fixture 均为根据公开结构重新制作的最小脱敏样本，不包含完整官网页面、图片、脚本、Cookie、评价或个人信息。

覆盖场景：

- 三品牌核心设备发现和范围外过滤；
- 华为国补/换购营销文案与直接售价隔离；
- OPPO 一加、保障服务和外部链接过滤；
- vivo iQOO、第三方配件和外部链接过滤；
- 多版本、多颜色、官方 SKU ID、划线原价、当前售价和销售状态；
- 国补价、券后价和以旧换新到手价拒绝；
- 三品牌完整入库连续执行两轮不产生重复目录或价格历史；
- 两轮生成的六份最小原始证据均可离线重放。

## 7. 尚未满足的生产退出条件

以下事项必须在公司网络、审批和专用测试窗口内逐品牌执行：

1. 法务或数据负责人确认五个商城的用途、频率、证据保留和 User-Agent；
2. 保存当期 robots、服务条款和允许路径的人工复核记录；
3. 技术负责人批准每个新品牌的首次低频 smoke test；
4. 每品牌选择少量固定产品，人工核对每个 SKU 的规格、原价、售价和库存；
5. 检查发现数量、成功率、条件价格拒绝数和异常价格变化；
6. 逐品牌连续运行两个真实调度周期，确认无重复 SKU 和价格历史污染；
7. 上述验收完成前保持 `LIVE_CRAWL_ENABLED=false`。

因此，本报告中的“开发完成”不表示阶段 4 已获准生产上线。
