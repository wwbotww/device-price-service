## 维护方式

- 公司数据规模、实测结果和遗留项只在 `PROJECT_STATUS.md` 汇总，并链接对应验收证据；不要复制到每份设计文档。
- 操作命令集中在运行手册，测试流程集中在开发指南；字段细节由数据库设计和代码维护。
- 当前指南不按阶段追加流水账。阶段报告归档后保留当时结论，历史“下一步”、开关和授权不能当作现行指令。
- 已被替代的重复说明直接删除；仍有决策或验收价值的资料归档。旧文本可从 Git 历史恢复，无需另存多份计划快照。
- 更新目录或标题时同步修正链接。代码和测试是实现事实来源；遇到文档冲突先核对实现，不按旧报告恢复已删除的业务链路。
