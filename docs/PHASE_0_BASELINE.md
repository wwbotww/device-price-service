# 阶段 0：范围与合规基线

> 建立日期：2026-08-05  
> 技术基线状态：已完成  
> 生产采集授权状态：待公司法务/数据负责人确认

## 1. 已冻结的 V1 范围

- 地区：中国大陆；
- 币种：CNY；
- 品牌：Apple、华为、小米、OPPO、vivo；
- 品类：手机、平板、笔记本电脑、台式电脑、手表；
- 渠道：五个品牌的中国大陆官方直营网页商城；
- 数据粒度：可销售 SKU；
- 数据字段：官方页面明确展示的原价、无条件直接购买的当前售价和销售状态；
- 排除：起售价、第三方商城、国补、优惠券、会员、以旧换新、分期月供及子品牌；
- 系统边界：只负责采集、规范化、校验和 MySQL 入库，不提供业务查询 API；
- V1 基础设施：不使用 Redis 或消息队列。

详细规则以 [项目构建及实施方案](PROJECT_IMPLEMENTATION_PLAN.md) 为准。

## 4. 生产上线门禁

以下项目全部完成前，只允许使用本地 fixture、小规模人工 smoke test 和开发环境调试，不开启生产定时全量采集：

- [ ] 公司法务或数据负责人确认五个渠道的采集用途和频率；
- [ ] 对五个站点逐一保存当期 robots 和服务条款检查记录；
- [ ] 确认 User-Agent 中可公开使用的公司名称和联系邮箱；
- [ ] 确认生产出口 IP、请求频率和告警联系人；
- [ ] 确认原始页面证据的保留期限和访问权限；
- [ ] 确认不存在登录、验证码绕过、签名破解或个人信息采集；
- [ ] 技术负责人批准首次生产 smoke test。

## 5. 当前允许的开发活动

- 构建数据库、迁移、Repository 和事务逻辑；
- 使用人工保存、脱敏后的 HTML/JSON fixture 开发解析器；
- 使用 Docker MySQL 8.4 代替公司 MySQL 做兼容性测试；
- 在低频、人工触发、明确白名单的前提下做少量公开页面 smoke test；
- 不得把开发测试自动扩展为持续生产采集。
